# Adapters (placeholder)

Adapter files tell the Gate which URL, button or field to use in this shop app.

- T2 adds `api.yaml` (HTTP adapter).
- T1 adds `browser.yaml` (browser adapter).

Start from the examples in the evidence-gate repo: `contract/examples/api.adapter.yaml` and `contract/examples/browser.adapter.yaml`.

Do not edit the shop code to fit the adapter; change the adapter instead.
